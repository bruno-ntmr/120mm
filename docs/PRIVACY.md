# Конфиденциальность

Приложение хранит журнал, профили людей и настройки локально в хранилище WebView
на телефоне или браузера. Учётная запись и облачный сервер не используются.
Измерения не отправляются разработчику. Телеметрия и рекламные SDK не включены.

Bluetooth нужен для поиска прибора, подключения и обмена измерениями.
На старых версиях Android системное разрешение местоположения может требоваться
для BLE-поиска; приложение не запрашивает координаты пользователя.

CSV/JSON создаются только по действию пользователя; место сохранения выбирается
через системный диалог. Экспорт может содержать имена и медицинские данные.
Удаление профиля оставляет измерения без владельца. Очистка данных приложения
или удаление приложения может удалить локальную историю; перед этим сохраните JSON.

Политика относится к этому коду. Сборки сторонних авторов могут отличаться.
