# 120mm

Локальный журнал измерений: Android-приложение и веб-клиент с общим интерфейсом.

- История давления и пульса, график, выбор дня, недели и месяца.
- Отдельные люди и перенос измерений между ними.
- Bluetooth-синхронизация и наблюдение за измерением на совместимом приборе.
- Русский и английский интерфейс: язык выбирается по основной локали системы при запуске; для остальных языков — английский.
- JSON-архив и CSV-экспорт, светлая/тёмная тема Android.
- Без учётной записи, сервера, аналитики и облачной отправки измерений.

Сейчас проверен только **Omron X1-G / SI.W03.01.00**. Протокол других моделей не поддерживается.
Проект независимый, не является официальным приложением производителя.
Это журнал данных прибора, а не диагностическая система. Приложение не запускает измерение дистанционно.
Android-наблюдение работает при открытом приложении; постоянная фоновая работа не реализована.

## Разработка

Нужны Node.js 22, Java 21 и Android SDK с `platforms;android-36` и `build-tools;36.0.0`.

```sh
npm ci --prefix mobile
npm test --prefix mobile
node --test tests/*.test.mjs
npm run sync --prefix mobile
```

Для локального APK задайте `JAVA_HOME` и `ANDROID_HOME`, затем:

```sh
bash mobile/scripts/apk.sh
```

Результат — `mobile/releases/120mm-dev.apk`. Обычная сборка **не меняет версию**.
Java/SDK/Gradle caches и зависимости не нужно добавлять в Git.

Для веб-клиента:

```sh
npm start --prefix web
```

Откройте `http://127.0.0.1:8765` в Chrome с Web Bluetooth.

## Релиз

[Инструкция по ключу подписи, GitHub Secrets и релизным тегам](docs/RELEASING.md).
Обычные push/PR запускают тесты и сборку веб-части. Только push тега `vX.Y.Z`
запускает сборку Android, подпись APK и создание **черновика** GitHub Release.
Публикация черновика — отдельное ручное действие.
